# Realt Neo — Портал недвижимости (realt.by edition)

Современный архитектурный портал недвижимости с каталогом объектов, реальными ценами и описаниями в стиле realt.by, калькулятором кредита и встроенной поддержкой публикации на GitHub Pages.

---

## 🚀 Как запустить на GitHub Pages (Пошаговая инструкция)

Чтобы любой человек в интернете мог зайти на ваш сайт:

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зелёную кнопку **"New"** (Создать новый репозиторий).
3. Введите название репозитория (например, `realt-neo` или `realt-belarus`).
4. Выберите **Public** (Публичный) и нажмите **"Create repository"**.

### Шаг 2. Загрузите файлы в репозиторий
В терминале вашей папки с проектом выполните команды:

```bash
# Инициализация git (если еще не сделана)
git init

# Добавление всех файлов
git add .

# Создание первого коммита
git commit -m "Initial commit: Realt Neo application"

# Привязка к вашему репозиторию на GitHub (замените ВАШ_АККАУНТ и ВАШ_РЕПОЗИТОРИЙ)
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git

# Отправка файлов в репозиторий
git push -u origin main
```

### Шаг 3. Включите GitHub Pages
1. Откройте ваш репозиторий на GitHub.
2. Перейдите во вкладку **Settings** (Настройки) ⚙️.
3. В левом меню нажмите на раздел **Pages**.
4. В блоке **"Build and deployment"** в выпадающем списке **Source** выберите **"GitHub Actions"**.
*(В репозитории уже настроен автоматический файл `.github/workflows/deploy.yml`)*
5. Через 1-2 минуты GitHub автоматически соберет проект и вверху появится ссылка:
   `https://ВАШ_АККАУНТ.github.io/ВАШ_РЕПОЗИТОРИЙ/`

## 🛠️ Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка статических файлов для хостинга
npm run build
```
Папка `dist/` содержит полностью готовые статические HTML/CSS/JS файлы с относительными путями (`base: './'`), которые работают на любом сервере или CDN.
