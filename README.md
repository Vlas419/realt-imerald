## 🚀 Как запустить на GitHub Pages (Пошаговая инструкция)

Чтобы любой человек в интернете мог зайти на ваш сайт:

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зелёную кнопку **"New"** (Создать новый репозиторий).
3. Введите название репозитория (например, `realt-imerald` или `realt-belarus`).
4. Выберите **Public** (Публичный) и нажмите **"Create repository"**.

### Шаг 2. Загрузите файлы в репозиторий
В терминале вашей папки с проектом выполните команды:

```bash
# Инициализация git (если еще не сделана)
git init

# Добавление всех файлов
git add .

# Создание первого коммита
git commit -m "Initial commit: Realt Imerald application"

# Привязка к вашему репозиторию на GitHub (замените ВАШ_АККАУНТ и ВАШ_РЕПОЗИТОРИЙ)
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git

# Отправка файлов в репозиторий
git push -u origin main
```

### Шаг 3. Включите GitHub Pages
1. Откройте ваш репозиторий на GitHub.
2. Перейдите во вкладку **Settings** (Настройки ⚙️).
3. В левом меню нажмите на раздел **Actions ➔ General**:
   - Прокрутите в самый низ до блока **Workflow permissions**.
   - Выберите **Read and write permissions** (Разрешить запись, чтобы робот мог опубликовать файлы). Нажмите **Save**.
4. В левом меню откройте раздел **Pages**:
   - В поле **Source** выберите **Deploy from a branch**.
   - В поле **Branch** выберите ветку **gh-pages** и папку **/(root)**. Нажмите **Save**.
5. Всё! Через 30 секунд вверху появится зелёная ссылка на ваш рабочий сайт!

---

### ❓ Что делать, если при первой сборке возник красный крестик (Failed):
1. Убедитесь, что в **Settings ➔ Pages ➔ Source** выбрано именно **GitHub Actions**, а не *Deploy from a branch*.
2. В терминале отправьте обновленный файл workflow:
   ```bash
   git add .
   git commit -m "fix: update workflow and dependencies"
   git push
   ```
3. Во вкладке **Actions** нажмите кнопку **"Re-run all jobs"** (Перезапустить). Сборка станет зелёной!

## 🛠️ Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка статических файлов для хостинга
npm run build
```
Папка `dist/` содержит полностью готовые статические HTML/CSS/JS файлы с относительными путями (`base: './'`), которые работают на любом сервере или CDN.
